# Phase 5 — Projector Wall Surface Calibration (PLANNED)

## Overview
Phase 5 supports projecting HoloLearn AI onto any flat classroom wall, board, or table, allowing teachers to write on the physical surface using the Smart Stylus.

## Planned Calibration Sequence
```text
Project 4 Calibration Targets -> Touch Corners with Stylus -> Calculate 4-Point Homography Transformation Matrix -> Map Physical Wall (X, Y) to Canvas (X, Y)
```
*Note: This phase is documented for future hardware integration and is not active in the current digital prototype.*

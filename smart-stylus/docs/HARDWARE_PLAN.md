# Physical Hardware Design Plan (PLANNED)

## Target Components
- **Microcontroller**: ESP32-S3-Mini (BLE 5.0, 240MHz dual-core CPU).
- **Tip Sensor**: Interlink Electronics FSR 400 series pressure resistor.
- **Positioning**: 40kHz Ultrasonic Receiver Transducer module.
- **Power System**: 250mAh LiPo battery with TP4056 USB-C charging IC.
